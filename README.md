# Mahmoud Amer | Personal Portfolio

A personal portfolio website showcasing my background, technical skills, projects, and journey as a software developer.

## Overview

This portfolio serves as a central place to explore my work, discover the technologies I use, and learn more about my experience and interests in software development.

Built with simplicity, accessibility, and responsiveness in mind, it features a clean interface with interactive elements and multiple visual themes.

## Features

- **Responsive Design:** Adapts to different screen sizes and devices.
- **Multiple Themes:** Switch between Light, Dark, and Violet themes.
- **Interactive Navigation:** Smooth navigation between portfolio sections.
- **About Me:** An introduction to my background and interests.
- **Skills Showcase:** An overview of my programming languages and development tools.
- **Projects Showcase:** Selected projects with descriptions and GitHub links.
- **Interactive Terminal:** Explore portfolio information through terminal-style commands.
- **Contact Section:** A contact form with client-side input validation.
- **CV Download:** Download my resume directly from the website.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and semantic markup |
| CSS3 | Styling, layouts, animations, and responsive design |

## Getting Started

You can run this project locally by following these steps:

**1. Clone the repository**

```bash
git clone https://github.com/MahmoudAmer0a/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Run the website**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.
